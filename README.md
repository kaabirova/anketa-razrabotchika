🚀 Анкета разработчика
Простая, лаконичная и стильная веб-форма, предназначенная для сбора первичной информации о навыках, технологическом стеке и предпочтениях соискателей или участников IT-сообществ.

📋 Обзор проекта
Этот проект представляет собой фронтенд-реализацию формы опроса. Дизайн выполнен в светлых тонах с яркими фиолетовыми акцентами, что делает интерфейс дружелюбным и современным.

Основные разделы анкеты:
Персонализация: Поле для ввода имени.

Стек технологий: Выбор основного языка программирования (Single Choice).

Опыт работы с инструментами: Выбор используемых фреймворков (Multiple Choice).

Формат работы: Уточнение предпочтений по удаленному графику.

Личный блок: Свободное текстовое поле для описания хобби и интересов.

✨ Особенности
Интуитивный UX: Четкое разделение на смысловые блоки.

Валидация: Поля настроены для корректного сбора данных (использование radio для единственного выбора и checkbox для множественного).

Адаптивность: Форма корректно отображается как на десктопах, так и на мобильных устройствах.

Стильный UI: Использование акцентного фиолетового цвета (#8A2BE2 или аналогичного) для заголовков и кнопок.

🛠 Технологический стек
Проект реализован с использованием классических веб-технологий:

HTML5: Семантическая разметка формы.

CSS3: Стилизация элементов, работа с отступами и цветовой схемой.

JavaScript (опционально): Для обработки события отправки формы и вывода данных в консоль или на сервер.
